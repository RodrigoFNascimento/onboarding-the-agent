# 03: the same instructions as AGENTS.md

[`AGENTS.md`](AGENTS.md) is the open-format version of the Orders API's
[`.github/copilot-instructions.md`](../02-orders-api/.github/copilot-instructions.md): same
content, placed at the repository root instead of in `.github/`, and read by many agents.

It lives in its own folder on purpose. A repo should use one file or the other, never
both with the same rules. The scoped instructions, skill and custom agent stay where they
are either way.
